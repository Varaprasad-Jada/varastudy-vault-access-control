# VaraStudy Vault Access Control

A WordPress plugin for managing contributor permissions and content submissions in an academic study-resource website.

## Features

- **Course-based access:** Assign contributors to permitted course groups.
- **Semester restrictions:** Configure the semesters contributors are allowed to work with.
- **Admin-managed assignments:** Administrators manage contributor access.
- **Submission approval workflow:** New contributor submissions can be reviewed before publication.
- **Contributor content ownership:** Contributors can work on their own drafts and pending submissions, subject to configured permissions.
- **Role-based access control:** Separates contributor permissions from administrative responsibilities.

## Intended Use

Designed for academic resource websites that organize subjects, study materials, and question papers by course and semester.

## Installation

1. Download or clone this repository.
2. Locate the plugin source directory.
3. Package the actual plugin files into a ZIP that preserves the plugin's required directory structure.
4. In WordPress, navigate to **Plugins → Add New Plugin → Upload Plugin**.
5. Upload the installable plugin ZIP and activate it.
6. Configure contributor assignments and permissions in the WordPress administration area.
